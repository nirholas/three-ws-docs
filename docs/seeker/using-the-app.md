# Using the Seeker app

| Surface | What it does |
|---|---|
| **Home** | One-tap Seed Vault sign-in, a Create and Explore grid, your agents, Seeker verification |
| **Selfie to avatar** | One photo with the Seeker camera becomes a rigged 3D avatar in about a minute |
| **Describe it** | A text prompt becomes an avatar |
| **Upload a GLB** | Bring a model you already have, or share one from any app |
| **Marketplace** | Agents from the community: drag to orbit, tap to inspect, open one to chat |
| **My agents** | Everything you own |
| **Share sheet** | Share a photo from any app and it opens the selfie flow; share a `.glb` and it opens the upload flow |
| **Shortcuts** | Long-press the icon for Create, Discover, My agents |
| **Offline** | A branded offline screen that reloads when the network returns |

Your agents appear on the web app the moment you sign in there with the same wallet.
