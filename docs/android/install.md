# Install the Android APK

Until the Google Play listing is live, install the signed APK directly. This is called sideloading, and it is safe when you verify the file.

## Steps

1. On your phone, open [three.ws/apps/android](https://three.ws/apps/android) and tap the download button. The file is `three-ws-release.apk` from the [v1.0.0 release](https://github.com/nirholas/three.ws/releases/tag/v1.0.0).
2. Open the downloaded file. Android will ask you to allow installs from your browser (or your file manager). Allow it for this install.
3. Tap **Install**, then **Open**.
4. Optional but recommended: turn the "install unknown apps" permission back off for that browser afterwards.

## Verify before you install

Check the signing certificate against the fingerprint three.ws publishes: [Verify the APK](verify.md).

## Updates

Until Play is live, updates arrive as a new release. Download the new APK the same way and install over the top. Your account and agents live on three.ws, so nothing is lost.

## Requirements

Android 6.0 or later with Chrome installed and up to date (the app renders with Chrome's engine). A Solana wallet that supports Mobile Wallet Adapter is needed to sign in with a wallet; on a Solana Seeker or Saga that is Seed Vault.

## Remove it

Long-press the icon, then App info, then Uninstall.
