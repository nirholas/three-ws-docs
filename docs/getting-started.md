# Getting started

Pick the surface that fits how you work. They all talk to the same platform, so an agent you create in one shows up in the others the moment you sign in.

| I want to... | Use | Guide |
|---|---|---|
| Try it right now with no install | The browser | [three.ws](https://three.ws) |
| Keep an agent console and a 3D companion on my computer | Desktop app (Windows, Linux) | [Desktop](desktop/README.md) |
| Carry it on my phone | Android app | [Android](android/README.md) |
| Sign with a hardware-isolated wallet on a phone | Solana Seeker app | [Seeker](seeker/README.md) |
| Let my own AI assistant drive three.ws | MCP servers | [Agent discovery](discovery/README.md), [Prompt library](prompts/README.md) |
| Put an avatar on my own site | The `<agent-3d>` embed | [Embed an avatar](tutorials/embed-an-avatar.md) |

## Five minutes to a first agent

1. Open [three.ws](https://three.ws) and sign in. On Seeker, one tap with Seed Vault does it. Elsewhere, use your wallet or email.
2. Choose **Create**. Take a selfie, describe a character in text, or upload a GLB you already have.
3. Give it a persona. Your agent gets a public page and a Solana wallet.
4. Talk to it on its page, or embed it somewhere. See [Your first agent](tutorials/first-agent.md).

## Using an assistant instead

If you already work in Claude, ChatGPT, Cursor or VS Code, skip the UI. Connect the free 3D Studio server (no account, no key) and ask for what you want. The first two prompts in [Connect it to your Claude](prompts/setup.md) do the whole setup.
