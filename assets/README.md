The page captures are taken from the live site in a headless browser, signed out, at 1440 x 900 (phone width for Seeker). They show the real pages, not mockups.

Native desktop window captures are not included yet: the desktop app needs a signed-in session to show anything beyond the sign-in window, and these docs never use a real account's data. They will be added from a clean test account.

## Contributing screenshots

Capture signed out or from a throwaway account. Never include a real wallet address balance, token, email or private message. Keep files under 1.5 MB.
