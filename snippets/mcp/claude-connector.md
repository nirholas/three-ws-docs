# Add three.ws as a Claude connector

1. Open Claude, then **Customize**, **Connectors**, **Add custom connector**.
2. Name: `three.ws`. URL: `https://three.ws/api/mcp` (OAuth 2.1).
3. For the free studio with no account, use `https://three.ws/api/mcp-studio` and set authentication to **None**.

One-click link: <https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=three.ws&connectorUrl=https%3A%2F%2Fthree.ws%2Fapi%2Fmcp>
